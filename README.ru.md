# Наш чат

[English](README.md) · **Русский**

Общий чат для людей, которые работают в Claude под одним аккаунтом.

![Наш чат: переписка, голосовое с расшифровкой и ответ Claude](docs/screenshot.png)

## Зачем

Когда несколько человек заходят в Claude под одним логином, у них общая история разговоров, но нет способа написать друг другу. «Наш чат» — это страница-артефакт внутри Claude. Её закрепляют в боковом меню, и у всех, кто входит в аккаунт, появляется общий мессенджер. Сообщения подписываются ником, который каждый выбирает сам на своём устройстве.

## Что умеет

- Переписка как в Telegram: ответы, реакции, закреп, поиск, правка своих сообщений, темы оформления. На телефоне действия с сообщением открываются долгим нажатием.
- Каналы и группы, как в Discord: список слева, у каждого канала свои непрочитанные и упоминания. Группу видят только её участники.
- Голосовые каналы: «Войти» открывает звонок в Jitsi Meet в новой вкладке, а в чате видно, кто сейчас в канале. Кнопка (i) у раздела «Голосовые» объясняет, как это работает.
- Фото, видео и файлы.
- Голосовые: плеер с волной и расшифровка текстом под ним (про микрофон — в «Ограничениях»).
- Кружки: круглое видео до минуты. После записи кружок показывается над полем ввода, «Отправить» сжимает его до квадрата 480 пикселей в MP4, кольцо показывает прогресс. Если браузер не умеет сжимать, ролик до 20 МБ уходит как есть. В ленте кружок без звука крутится сам, по тапу играет со звуком.
- Гости с других аккаунтов: читают всё и пишут текстом, у ника всегда «(гость)» (см. «Пригласить людей с другого аккаунта»).
- Помощь прямо в чате: кнопка «?» слева вверху и вкладка «Помощь» в панели.
- `@claude`: общий помощник отвечает прямо в чате, опираясь на общую память и карточки людей.
- Личный агент у каждого участника («Мой агент» вверху слева): личный разговор, сводка каналов, черновики сообщений, которые отправляешь сам, заметки и напоминания. Работает на твоём Claude. Разговор скрыт от гостей, но не от своих под общим входом. Других агентов зовут `@ник-агент`.
- Файлы с компьютера коллеги: кнопка «Попросить файл» в «Команде». Отправляет только сам хозяин компьютера, подтверждая каждый файл в своём Claude Code; брать можно только из папок, которые он разрешил, а ключи, пароли и скрытые файлы не уходят никогда. Под запросом честный статус: ждёт подтверждения, компьютер не в сети, отказано, отправлено, истёк.
- `@ник`: если человека нет в сети, за него отвечает его агент по карточке, которую человек заполнил сам.
- Передача работы: карточка «что сделано / что дальше», которую можно отдать Claude в соседнем разговоре.
- Общая память, которую учитывают Claude и агенты.
- Скилл для Claude Code: «напиши в наш чат», «что нового в чате», «спроси у Ани», «отправь голосовое», «что в голосовых».

## Как устроено

- `page/nash-chat.html` — сама страница. Сообщения хранятся в базе артефакта (возможность `db`), файлы и записи — в его хранилище (`assets`), «кто в сети» показывает `room`, ответы Claude идут через `sample`.
- `skill/nash-chat/` — скилл для Claude Code: тот же чат из терминала или приложения Claude. Формат данных описан в `reference.md`.
- Каждое устройство пишет только в свои документы (один на день), поэтому одновременные сообщения не затирают друг друга.

## Быстрый старт

Нужен Claude Code, который умеет публиковать артефакты (приложение Claude или `claude` в терминале). Пять шагов, минут пять:

1. Скачай репозиторий:

   ```bash
   git clone https://github.com/danial112233/claude-nash-chat.git
   ```

2. Попроси Claude Code опубликовать страницу:

   > Опубликуй claude-nash-chat/page/nash-chat.html как артефакт с возможностями assets, db, downloads, room, sample и user и закрепи его в боковом меню.

   Claude пришлёт ссылку вида `https://claude.ai/artifact/…`.

3. Поставь скилл и впиши в него ссылку на свой чат:

   ```bash
   python3 claude-nash-chat/install.py https://claude.ai/artifact/<id твоего чата>
   ```

   Скилл появится в `~/.claude/skills/nash-chat`. Поставь его так же на других компьютерах, с которых заходят в аккаунт.

4. Открой чат, выбери ник и аватарку, заполни карточку для агента.
5. Позови людей. С того же аккаунта достаточно ссылки на чат. С другого аккаунта — по разделу ниже.

Для голосовых из Claude Code пригодятся, но не обязательны:

- `ffmpeg`: скилл переводит любую запись в webm и рисует волну;
- команда `stt <файл>`, которая печатает текст записи (например, своя обёртка над faster-whisper). С ней скилл расшифровывает голосовые, и текст видят все.

## Пригласить людей с другого аккаунта

1. Открой чат, нажми «Поделиться» и пригласи человека по почте с ролью «Наблюдатель» или «Комментатор». Доступ по ссылке не включай.
2. Человек открывает ссылку из письма, выбирает ник и видит пометку «ты гость». Читать он может всё, писать — текстом, а его сообщения помечены «гость».
3. Платформа не даёт гостю писать в базу чата, поэтому его текст доходит через страницу участника: сообщение уходит, как только чат открыт на экране хотя бы у одного участника. Удобнее всего держать закреплённый чат открытым в отдельном окне приложения Claude на компьютере, который обычно включён. До этого у гостя стоит «в очереди». Гость пишет только в #общий и открытые каналы, не чаще 5 сообщений в минуту. Голосовые, кружки и файлы гостям недоступны.
4. Гость читает всё: каналы, группы, общую память, карточки и ссылки на звонки. Паролей и личного в чат не пиши. Ник гостя всегда с «(гость)», а похожий на ник участника или на Claude становится просто «Гость».
5. Роль «Редактор» даёт гостю полную запись, но заодно право менять саму страницу, поэтому её лучше не давать.
6. Если нужно, чтобы люди писали всё без этих ограничений и без права менять страницу: тариф Team или Enterprise. Там людей добавляют в организацию с ролью «Участник».

## Ограничения

| Что | Почему | Как быть |
|---|---|---|
| Нет записи с микрофона | Платформа Claude не даёт странице-артефакту микрофон | На телефоне «Записать голосовое»: iPhone снимает ролик камерой, в чат уходит только звук; Android открывает диктофон. На компьютере — выбрать аудиофайл. Если платформа откроет микрофон, кнопка начнёт записывать сама |
| Голосовой канал — это вкладка Jitsi | Страница не может передавать звук | Разговор идёт в Jitsi Meet (meet.jit.si). Того, кто начинает звонок, Jitsi может попросить войти через Google или GitHub. Ссылка постоянная и длинная, но зайти по ней может любой, у кого она есть |
| Кружок сжимается только после «Отправить» | В приложении Claude на телефоне видео запускается только по нажатию | Нажми «Отправить» и дождись кольца. Если браузер не умеет сжимать, ролик до 20 МБ уходит как есть, больше — запиши короче |
| Голосовые с iPhone лежат как m4a в base64 | Хранилище не принимает аудио-MP4 без видео | Ничего делать не нужно: плеер заранее подгружает записи, и iPhone играет сразу по тапу |
| Страница не расшифровывает речь | Распознавания речи в артефакте нет | Расшифровки делает Claude Code на компьютере, где есть `stt` |
| Гость пишет, только пока чат открыт у участника | Гостю нельзя писать в базу, его текст переносит страница участника | Держи закреплённый чат открытым в отдельном окне на компьютере, который обычно включён |
| Гость читает всё, группы тоже | Доступ к артефакту — это доступ ко всей его базе | Не пиши в чат пароли и личное. Группа скрывает себя только из списка |
| Агент коллеги отвечает, только пока чат открыт хотя бы у кого-то | Ответ агента делает открытая страница | Если ответа нет, он придёт, когда чат откроют |
| Файл с компьютера коллеги приходит, только пока его компьютер включён | Отправляет сессия Claude Code на его компьютере и только с его подтверждения | Он включает выдачу у себя (скилл: «включи выдачу файлов»), подтвердить можно и с телефона через Remote Control. Запрос ждёт сутки |
| Подписаться можно любым ником | Аккаунт общий, ник хранится на устройстве | Чат рассчитан на своих. Знакомое устройство только предлагает ник, сам он не выбирается |
